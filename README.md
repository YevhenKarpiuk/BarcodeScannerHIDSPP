# BarcodeScannerHIDSPP

Внешняя компонента Native API для сканеров штрихкодов в 1С на Android.
Поддерживает клавиатурный режим HID и прямое Bluetooth-соединение SPP.

## Режимы

- **HID:** ввод до Enter, обязательный префикс `@@`; префикс и пробельные символы удаляются.
- **SPP:** подключение к уже сопряжённому Bluetooth-устройству по имени через RFCOMM. Данные декодируются как UTF-8; штрихкод завершается символом CR, последующий LF пропускается. Префикс `@@` не требуется.

Для SPP устройство предварительно сопрягается средствами Android.
Код запрашивает `BLUETOOTH_CONNECT` на Android 12 и выше. После выдачи
разрешения при необходимости повторите включение компоненты.

## API 1С

Класс сохраняет имя `BarcodeScannerHID`.

| Элемент | Назначение |
|---|---|
| `Enable()` / `Disable()` | Запустить / остановить получение данных |
| `GetBarcode()` | Последний штрихкод |
| `GetDescriptionLastError()` | Последняя ошибка |
| `IsEnabled` | Флаг включения; запуск/остановка выполняются методами |
| `ForProcessing` | Флаг координации обработки |
| `ModeSPP` | `Истина` — SPP, `Ложь` — HID |
| `SPPDeviceName` | Имя сопряжённого сканера |

Уведомление: источник `BarcodeScannerHID`, событие `OnChange`, данные `_`.
Результат читается через `GetBarcode()`.

```bsl
Если ПодключитьВнешнююКомпоненту("ОбщийМакет.Компонента", "Scanner", ТипВнешнейКомпоненты.Native) Тогда
    Компонента = Новый("AddIn.Scanner.BarcodeScannerHID");
    Компонента.ModeSPP = Истина;
    Компонента.SPPDeviceName = "ИмяСканера";
    Компонента.Enable();
КонецЕсли;

// В обработчике внешнего события BarcodeScannerHID / OnChange:
Штрихкод = Компонента.GetBarcode();
```

Имя макета и сканера в примере замените своими.
Идентификаторы библиотеки, Java-пакета и класса совпадают с BarcodeScannerHID;
этот проект используется как альтернативный вариант компоненты.

## Структура и сборка

- Корень: C++-реализация Native API и преобразование строк.
- `include/`: интерфейсы SDK внешних компонент 1С.
- `Android_Proj/src/`: Java-часть; связь с C++ через JNI.
- `Android_Proj/jni/`: настройки NDK и вспомогательный JNI-код.
- `Config/`: манифест пакета компоненты.
- `prebuilt/`: существующие APK, SO и, при наличии, ZIP из исходной папки. Их соответствие текущим исходникам и работа на устройстве не проверены.

Исходные настройки: Android Gradle Plugin 3.3.0, Gradle 4.10.1, SDK 28,
Build Tools 28.0.3, библиотека Android Support 28.0.0.
NDK настроен на ARMv7, ARM64, x86 и x86_64. Старый toolchain может требовать
совместимого JDK/NDK и доступности прежних репозиториев зависимостей.

В Windows задайте `JAVA_HOME`, `ANDROID_HOME`, `ANDROID_NDK`, перейдите в
`Android_Proj` и выполните `make.bat`. Скрипт собирает Java и C++ и копирует
результаты в `Android_Proj/publish/`.

Для поставки в 1С поместите APK, соответствующие SO и `Config/MANIFEST.XML`
в корень ZIP. Имена файлов должны совпадать с манифестом. При отсутствии
библиотеки для архитектуры удалите соответствующие записи из манифеста пакета.
ZIP подключается в 1С как внешняя компонента типа Native.

Исходники опубликованы без изменения логики. Сборка и испытания на Android
при подготовке публикации не выполнялись.
